POWER BI DASHBOARD SETUP

1. Open Power BI Desktop.
2. Get Data > Excel > select Sample data (1).xlsx.
3. Load the sheet containing the 700-row dataset.
4. In Power Query:
   - Set Date to Date type.
   - Set Sales, Profit, Units Sold, Sale Price and Manufacturing Price to numeric types.
   - Replace blank Discount Band values with "Unknown".
5. Rename the table to Cleaned_Data.
6. Create the DAX measures from PowerBI_DAX_Measures.txt.
7. Import PowerBI_Theme.json from View > Themes > Browse for themes.
8. Create the dashboard:
   - KPI cards: Total Sales, Total Profit, Units Sold, Profit Margin %.
   - Line chart: Date/Month on X-axis; Total Sales and Total Profit as values.
   - Bar chart: Country vs Total Sales.
   - Bar chart: Product vs Total Sales.
   - Bar chart: Segment vs Total Sales.
   - Slicers: Year, Country, Segment, Product, Discount Band.
9. Turn on interactions so every slicer filters every visual.
10. Save as Week_4_Sales_Analytics.pbix.

IMPORTANT:
A .pbix file is a proprietary Power BI Desktop binary and cannot be reliably generated by this environment. This package contains the complete data, DAX, theme, and dashboard design so the PBIX can be created directly in Power BI Desktop without rebuilding the analysis.
